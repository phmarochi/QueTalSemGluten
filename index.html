Para quem é

Se você já leu rótulo no meio do mercado tentando descobrir se dá para comer, este lugar é para você.

  • Quem tem doença celíaca

    Cozinha dedicada, sem trigo circulando. Você come sem ficar calculando risco depois.

  • Quem é sensível ao glúten

    Inchaço, gases, cansaço depois do pão. Dá para tirar o glúten sem tirar o prazer de comer.

  • Quem quer comer melhor

    Menos ultraprocessado, mais comida de verdade. Sem glúten não é sinônimo de saudável — o que importa é como é feito.
